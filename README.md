# shangchengAI

## Project overview
shangchengAI is an AI-powered assistant focused on helping users navigate German Ausländerbehörde workflows, providing guidance and responses tailored to official processes and requirements.

## Setup
1. Install dependencies.
   ```bash
   npm install
   ```
2. Set your API key (example for OpenAI-compatible providers).
   ```bash
   export OPENAI_API_KEY="your_api_key_here"
   ```

## Run
- Dev server:
  ```bash
  npm run dev
  ```
- Backend:
  ```bash
  npm run backend
  ```

## Scope restriction
This project is intentionally limited to German Ausländerbehörde topics. Responses and functionality should stay within that scope.
